# 3. In-Degree PageRank for Symbol Centrality

We decided to rank code symbols in structural maps, disambiguation queries, and search listings using in-degree PageRank centrality computed over the dependency graph.

Static file-order dumps waste agent context tokens on peripheral leaf functions while burying foundational architectural abstractions. In-degree PageRank prioritizes types, traits, and core utilities that have the highest number of dependent inbound references across the codebase.
